# Error Codes (core subset)

## Compiler errors
- `unknown_character` a character that isn't part of Check
- `unclosed_string` a string with no closing quote
- `unknown_escape` an unknown escape in a string (`\q`)
- `unclosed_interpolation` a `{` in a string that never closes, or holds no expression
- `leading_zero` a number starting with `0` followed by digits (`017`)
- `malformed_number` any other malformed number (`.5`, `0XFF`, `1E3`, `0b12`)
- `unexpected_token` an unexpected token (the general syntax error)
- `unclosed_bracket` a bracket or brace that never closes
- `trailing_separator` a `,` or `;` at a line end or before `]`, `)` or `}`
- `else_on_new_line` `else` on the line after `}`
- `foreign_operator` an operator from another language (`%`, `&&`, `||`, `!`)
- `assignment_in_condition` `=` in a condition
- `arrow_without_braces` a function with `->` and no braces
- `arrow_before_braces` `=>` before a body in braces
- `body_without_arrow` a body without braces and without `=>`
- `var_in_declaration_pattern` `var` inside a `let` or `var` declaration's pattern
- `let_in_class_header` `let` before a field in a class header, where fields are `let` unless written `var`
- `readonly_let` `readonly` on a `let` field, which is already read-only
- `arrow_on_new_line` a `=>` body that starts on the line after
- `semicolon_in_arrow_body` a `;` in a function's `=>` body, which needs braces for more than one statement
- `unknown_name` a name that doesn't exist
- `duplicate_name` a name defined twice in the same block or file
- `redefined_builtin` redefining or shadowing `Maybe`, `Some`, `None`, `Result`, `Ok` or `Err`
- `used_before_declared` a variable or `let` lambda used above its own line
- `used_before_set` a function run before a top-level variable it uses is set
- `nested_named_function` a named function declared inside a function body
- `type_mismatch` a type mismatch (the general one)
- `type_needed` a type that can't be worked out and needs writing
- `wrong_arguments` the wrong number of arguments, or an unknown named one
- `unknown_method` a method that the type doesn't have
- `not_callable` calling something that isn't a function
- `invalid_operand_types` an operator used on types it doesn't work on (`"5" + 3`, `1 and 2`)
- `bitwise_on_bool` a bitwise operator on `Bool`s (suggests `and`, `or`)
- `chained_comparison` chained comparisons (`a < b < c`)
- `slash_for_int` `/` where an `Int` is expected (suggests `div`)
- `branch_type_mismatch` `if` and `else` branches of different types, used as a value
- `return_type_mismatch` return paths of different types
- `recursion_without_return_type` a recursive function without `->`
- `literal_too_big` a number literal too big for its type
- `negative_literal_exponent` a negative literal exponent on an `Int` (`2 ** -1`)
- `unhandled_maybe` a `T?` used where a `T` is needed
- `doubled_maybe` a `T?` body in an `if` without `else` or a value loop, where a plain `T?` is expected
- `flatten_without_nesting` `flatten()` on a `T?` with nothing nested
- `not_iterable` `for` over something that isn't a list or range
- `try_outside_failable` `try` in a function that returns neither a `Maybe` nor a `Result` (added by the agent while building, 2026-11-14)
- `try_result_in_maybe` `try` on a `Result` in a function returning a `Maybe` (suggests `try x.ok()`)
- `try_maybe_in_result` `try` on a `Maybe` in a function returning a `Result` (suggests `try x.orErr(...)`)
- `try_error_mismatch` `try` on a `Result` whose error type differs from the function's
- `assign_to_let` assigning to a `let`
- `assign_to_parameter` assigning to a parameter not written `var`
- `change_let_collection` changing a `let` list, map or set (`push`, `pop`, `removeAt`, `add`, `remove`)
- `invalid_key_type` a map key or set item whose type has no exact equality (`Float`, a function, a collection, a `ref class` or anything holding one)
- `break_outside_loop` `break` or `continue` outside a loop
- `return_outside_function` `return` outside a function
- `loop_value_without_break` a `for`, `while` or `loop` used as a value with no `break` value
- `break_type_mismatch` `break` values of different types in one loop
- `constant_backwards_range` a backwards range with constant ends (`10..0`)
- `nested_type` a class or enum declared inside a function body
- `mixed_fields` a variant, record literal or record type with both named and positional fields
- `record_to_class` a record value, not a literal, used where a class is expected (`let q: Point = t`)
- `spread_not_first` a `...` spread that isn't first in a call or record literal, or a second one
- `this_outside_method` `this` outside a method
- `unknown_field` a field that the type doesn't have
- `unqualified_variant` a variant written without its enum where the expected type isn't known (`let s = Circle(1.0)`)
- `non_exhaustive_match` a `match` that misses a case, named in the message
- `or_pattern_bindings` alternatives of an or-pattern that bind different names
- `let_else_can_finish` a `let ... else` whose `else` can finish
- `const_not_constant` a `const` whose value isn't a constant expression
- `const_cycle` consts defined in terms of each other
- `external_outside_library` an `external` function outside a library package
- `misplaced_namespace` a `namespace` line that isn't the first line of the file
- `missing_import` an import of a file or folder that doesn't exist
- `folder_without_slash` a folder import without its trailing `/` (`import "lib"`)
- `imported_entry_file` an import of a file that has imports or top-level statements
- `overlapping_imports` two imports that cover the same file (`import "lib/"` and `import "lib/a.check"`)
- `private_import_in_run` `import private` in a program being run, not tested
- `ambiguous_name` a name found in more than one namespace in scope, with no qualification
- `private_name` a `private` declaration used outside its unit
- `private_member` a `private` field or method used outside its type, or passed to its constructor
- `readonly_field` a `readonly var` set outside its class, including by `...` copying
- `private_field_without_default` a `private` field with no default, which the constructor can't set
- `wrong_type_arguments` a generic type with the wrong number of type arguments (`Box` or `Box<Int, Int>` for `Box<T>`)
- `not_an_interface` a type named after `:` in a type's header, or before `for` in `implement`, that isn't an interface
- `unmet_constraint` a type argument that doesn't implement the interfaces its parameter needs (`<T: Shape>`)
- `missing_implementation` a type missing a method or field an interface it implements requires
- `wrong_implementation` a method whose parameter or return types don't match its interface's
- `conflicting_defaults` two interfaces with defaults for the same method, which the type doesn't override
- `field_requirement_needs_class` an interface that requires fields, implemented by an enum or built-in type
- `implement_for_specific_arguments` an interface implemented for some of a generic type's arguments (`implement Shape for Box<Int>`), since they're erased at run time
- `list_needs_type` a list of values of different types with no declared element type (`let xs: Shape[] = ...`)
- `interface_field_extras` an interface field with a default, `private` or `readonly`, which only an implementing class can give it
- `code_in_pure_data` something other than a literal in a `.con` file (use `.conx` for computed values)
- `bad_data_name` a data file whose name isn't a valid name, or is a keyword or reserved name (`class.con`, `Ok.con`)
- `not_pure_data` a data file a host reads that isn't a `.con` file
- `data_folder` a folder of data files with no code, which will be one map once `Map` exists
- `namespace_outside_package` a file's namespace that doesn't start with its package's
- `import_cycle` units whose manifests import each other in a loop
- `unsupported_import` a `pkg:` or URL import, which isn't supported yet
- `unknown_host` a host other than `check:cli`, in `hostImport` or `import host`
- `misplaced_host_import` `import host` written twice, or in an entry file beside a `package.con`
- `missing_manifest` a folder run with no `package.con`
- `no_entry` a folder run whose `package.con` names no `entry`
- `missing_entry` a `package.con` `entry` file that doesn't exist

## Stops
- `try_stopped` a top-level `try` found `None` or an `Err` (shown after the message), so the program stopped (not a panic; exit status 1)

## Panics
- `panic_called` `panic(reason)` was called
- `integer_overflow` integer overflow
- `division_by_zero` integer division by zero (`div`, `mod`, or `/` with two `Int`s)
- `or_panic_on_none` `orPanic` on a `None`
- `or_panic_on_err` `orPanic` on an `Err` (shows the error)
- `negative_exponent` a negative exponent on an `Int`
- `shift_out_of_range` a shift amount below 0 or of 64 and above
- `round_out_of_range` rounding `NaN`, `Infinity` or a `Float` too big for an `Int`
- `stack_overflow` more than 10,000 nested calls
- `index_out_of_range` writing to a list index that doesn't exist (`list[9] = x`)
- `missing_key` a compound assignment or nested write to a map key that isn't there (`m[k] += 1`)
- `const_cycle` a `.conx` value that reaches itself through a function call while it's being built

## Warnings
- `unused_var` a `var` that's never reassigned
- `shadowed_name` a local that shadows a function or type
- `repeated_namespace` a `namespace` line that only repeats its package's, which the manifest already sets
- `interpolated_maybe` interpolating a `T?`
- `nested_maybe` an `if` or loop value that is a `T??`
- `let_else_some` `let Some(x) = e else { ... }`, which `let x = e ?? ...` replaces
- `record_beside_class` a record literal whose class is written right beside it (`let q: Point = (1, 2)`), which `let q = Point(1, 2)` replaces
